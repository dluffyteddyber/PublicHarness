# Public Harness

Started 5 Nov 2026. Status: **planning, nothing built yet.**

## The idea
A Folding@home-style network for AI. Individuals install a small client and connect their spare
computers (GPU or CPU) to a shared, worldwide pool. Vetted research projects send jobs to the pool:
model evaluations, batch inference, synthetic data, and later possibly training. The aim is to give
open AI research compute it could not otherwise afford.

(Another way to read the idea is still open: see [plan/open-items.md](plan/open-items.md), item 1.)
