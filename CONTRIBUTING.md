# Contributing

Thanks for helping. The project is at the planning stage, so the most useful help right now is
research and discussion, not code.

## Where things go
- **Ideas and questions** (including the open decisions in [plan/open-items.md](plan/open-items.md)):
  [Discussions](https://github.com/dluffyteddyber/PublicHarness/discussions).
- **A specific task or problem** (e.g. "survey Petals", "phases.md is missing X"): open an
  [Issue](https://github.com/dluffyteddyber/PublicHarness/issues).
- **Changes to the plan or code:** fork the repo, make a branch, open a pull request.
  Keep each PR to one topic and say why in the description.

## Good first contributions
- Phase 0 survey: pick a project from [plan/phases.md](plan/phases.md), check its current state, and
  write a short note in `plan/survey/<project>.md`: what it does, workloads, how it handles trust and
  sandboxing, licence, is it active, could we build on it. Link your sources.
- Point out problems or gaps in [plan/scope.md](plan/scope.md).

## Writing style
- Plain English, short sentences, outcome first.
- Dates as day month year (5 Nov 2026).
- Mark anything unverified as "to check".

## Conduct
Be kind and constructive. Don't post anyone's personal data. Don't propose uses of the network
that could cause harm; the project only runs vetted research jobs.
